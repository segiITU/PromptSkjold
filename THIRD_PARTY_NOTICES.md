## BardsAI Model Assets

Official public beta packages use the BardsAI EU multilingual PII anonymization
model:

- Model ID: `bardsai/eu-pii-anonimization-multilang`
- Provider: bards.ai
- License: Apache-2.0
- DOI: `10.57967/hf/8721`
- Source: https://huggingface.co/bardsai/eu-pii-anonimization-multilang

The package includes prepared runtime files under
`models/ner/bardsai-eu-pii-anonimization-multilang/`:

- `config.json`
- `tokenizer.json`
- `tokenizer_config.json`
- `onnx/model_q4f16.onnx`
- `onnx/model_q4f16.onnx.data`

The `model_q4f16.onnx` and `model_q4f16.onnx.data` files are modified/generated
Privacy Guardrail release artifacts. They are produced from upstream BardsAI
model files by the repository's conversion scripts using ONNX Runtime
MatMulNBits 4-bit weight-only quantization and ONNX external-data packaging.
They are not upstream-original BardsAI files.

The active conversion manifest in the release preparation workspace records:

- Method: `converted-float-to-fp16-then-q4f16`
- Quantization: 4 bits, block size 32, symmetric weights, `QOperator` format,
  `MatMul` operators
- `model_q4f16.onnx` SHA-256:
  `3e74fb3e23b59302d850f1cbbf12949d3bd77e9ae8890d866ed884f377b9c59c`

Inactive or intermediate model artifacts such as `model_fp16.onnx`,
`model_fp16.onnx.data`, `model_quantized.onnx`, conversion manifests, and local
source caches are excluded from official release ZIPs by the packaging rules.

## Bundled Model: Fine-Tuned From bardsai/eu-pii-multi-mini-preview

The bundled model is fine-tuned from `bardsai/eu-pii-multi-mini-preview` (an mMiniLMv2-L6-H384
token classifier, itself distilled from XLM-RoBERTa Large) by BardsAI. Modifications: further
fine-tuning on synthetic Danish and English data, vocabulary pruned to Danish and English
(about 25.7k tokens), and int8 quantization (about 21.8 MB). The fine-tuned model is published
separately on Hugging Face as `ermias-ai/da-pii-mini-preview-21m` (https://huggingface.co/ermias-ai/da-pii-mini-preview-21m, Apache-2.0 for PromptSkjold's own changes) with the
base model credited and the Microsoft licence text included. A browser demo is at https://huggingface.co/spaces/ermias-ai/da-pii-mini-preview-21m-demo. The BardsAI section above describes the model used by the earlier official beta
packages and does not cover this one.

## Fonts

Official packages include these bundled font files (in `fonts/`):

- IBM Plex Sans (interface text, titles, the PromptSkjold wordmark):
  `ibm-plex-sans-latin-400.woff2`, `-500`, `-600`, `-700`
- IBM Plex Serif (the text of the review letter only):
  `ibm-plex-serif-latin-400.woff2`, `-500`
- JetBrains Mono (debug output): `jetbrains-mono-400.woff2`, `jetbrains-mono-600.woff2`

IBM Plex Sans and IBM Plex Serif are Copyright (c) IBM Corp. and licensed under
the SIL Open Font License, Version 1.1; JetBrains Mono is Copyright (c) The
JetBrains Mono Project Authors under the same licence. The licence texts ship
next to the fonts: `fonts/LICENSE-IBM-Plex-Sans-OFL.txt`,
`fonts/LICENSE-IBM-Plex-Serif-OFL.txt` and `fonts/LICENSE-JetBrains-Mono-OFL.txt`
(source: `src/assets/fonts/`).

The IBM Plex files are the Latin subsets (Danish and English text, punctuation,
digits) as distributed by Fontsource (`@fontsource/ibm-plex-sans` and
`@fontsource/ibm-plex-serif`, version 5.3.0); the glyph outlines are not
altered. They are loaded under the CSS family names "PromptSkjold Sans" and
"PromptSkjold Serif", which is a stylesheet alias, not a rename of the font
files. The in-page interface (the content script that runs on the chat sites) embeds three
of these files, IBM Plex Sans 400 and 600 and IBM Plex Serif 400, as base64 (see
`scripts/build-page-assets.js`) so that the chat sites cannot detect the
extension through font URLs.
